# המפה השבועית שלי

אפליקציית ניהול זמן אישית — עוגנים קבועים, משימות עם רמת אנרגיה, לוח שבועי, פתקים לפי תחום, רשימת "אי־פעם" וסקירה שבועית.

קובץ אחד (`index.html`), בלי build, בלי שרת. כל הנתונים נשמרים בדפדפן (localStorage) — יש כפתור גיבוי/שחזור בתוך האפליקציה.

האתר החי: https://guyamsellem2-design.github.io/1/

## איך עורכים ומעדכנים

1. עורכים את `index.html` (כאן ב-GitHub ישירות, או לוקאלית ודוחפים שינויים).
2. כל שינוי ב-`main` מתפרסם אוטומטית לכתובת החיה תוך דקה-שתיים.
